# Laboratorio de Comportamiento Organizacional

Mini plataforma académica para la **Unidad II: Comportamiento Individual** de una Maestría en Administración.

## Objetivo
Desarrollar capacidad de diagnóstico y toma de decisiones gerenciales a partir de casos ambiguos, evitando reducir el comportamiento laboral a explicaciones simples basadas únicamente en personalidad.

## Contenidos
- Bases del comportamiento individual
- Roles gerenciales
- Personalidad y organizaciones
- Actitudes en las organizaciones
- Conductas en el lugar de trabajo
- Auditoría crítica de recomendaciones generadas por IA

## Casos incluidos
1. ¿A quién asciendes?
2. ¿Mala actitud o mal diagnóstico?
3. El gerente también es parte del problema
4. Comité Ejecutivo
5. AI Challenge

## Uso
El sitio funciona como una aplicación estática. Las decisiones del estudiante se guardan localmente en el navegador mediante `localStorage`.

Para publicarlo, activa **GitHub Pages** desde **Settings → Pages → Deploy from a branch → main / root**.
